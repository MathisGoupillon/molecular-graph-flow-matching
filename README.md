# Molecular Graph Generation — Research Code Samples

This repository contains selected code samples from my research internship at **Mohamed bin Zayed University of Artificial Intelligence (MBZUAI)**, where I worked on molecular graph generation using latent generative models.

The project explored the combination of **Flow Matching, Optimal Transport, Variational Flow Matching, and guidance methods** to generate molecular graphs through a learned latent representation.

## Repository Contents

The selected Python files cover several aspects of the research:

- **Flow Matching & Optimal Transport:** Training generative models in latent space using minibatch Optimal Transport couplings.
- **Variational Flow Matching:** Modeling endpoint distributions using probabilistic approaches.
- **Guidance Methods:** Steering the generation process using gradients from trained validity predictors.
- **Molecular Evaluation:** Evaluating generated molecules using validity metrics, FCD, and other molecular quality measures.

## Important Note

**This repository is intended solely as a collection of code samples for research internship and academic applications.**

It contains a deliberately selected subset of a larger research project and is **not intended to be a complete, standalone, or directly reproducible implementation**.

Some external dependencies, project-specific modules, datasets, and model checkpoints have intentionally been omitted.

The purpose is to provide examples of my research programming experience and the methods I worked on, rather than to distribute the full research framework.
